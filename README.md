# Fonctionnalités de l’application

Cocher `[x]` lorsqu’une fonctionnalité est terminée et laisser `[ ]` sinon.

## 1. Mes playlists
- [x] Afficher la liste des playlists enregistrées en base de données depuis le menu d’accueil.

## 2. Sélectionner une playlist
- [x] Rendre chaque playlist de la liste cliquable.
- [x] Afficher la playlist sélectionnée.
- [x] La définir comme playlist courante en la stockant en session.

## 3. Ajouter une piste
- [x] Proposer un bouton « Ajouter une piste » dans l’affichage d’une playlist.
- [x] Afficher un formulaire permettant de saisir les données de la piste.
- [x] Ajouter la piste à la playlist courante lors de la validation.

## 4. Créer une playlist vide
- [x] Proposer cette fonctionnalité dans le menu d’accueil.
- [x] Afficher un formulaire permettant de saisir le nom de la playlist.
- [x] Créer et enregistrer la playlist vide en base de données.
- [x] La définir comme playlist courante en la stockant en session.

## 5. Afficher la playlist courante
- [x] Proposer cette fonctionnalité dans le menu d’accueil.
- [x] Afficher la playlist stockée en session.
